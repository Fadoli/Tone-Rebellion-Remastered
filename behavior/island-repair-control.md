# Contrôle Repair de l'île

## Conclusions actuelles (les sections suivantes sont chronologiques; les « Rectification » remplacent les affirmations antérieures)

- Boutons de bâtiment: le `p1` réel vient de la table de boutons (`FUN_0042f150`), pas de `windows.txt`. Op 1: code 0 = OnOff (bit `0x400`), 2 = Upgrade (bascule marque/tâche), **3 = Repair** (marque de genre 0 + tâche type 4 sous-type 1, étiquette `REPAIR`),

- Le port couvre `BC_Repair`/`BC_Upgrade`/`BC_OnOff` et la réparation par évènements `REPAIR`; Attack/Defend/Recall/Obtain/TrnStk non portés.
