# Island navigation

- The island-window initialization path in `FUN_004337d9` (`islewin.cpp`) resolves the active map item, sets a 2560×320 world extent, and loads `data\island%02d.pal`, `data\island%02d.hzt`, `data\%s%02d.SHP`, and the island-specific `data\i%02d-feat.shp`. The default `island` SHP from the local COB has one 2560×320 frame. The remake loads that panorama and palette, crops a 640×320 viewport, and scrolls horizontally over the original image. `FUN_00461b3b` (`tworld.cpp`) reads `data\ISLAND%02d.TXT` into an ordered location table; the C parser preserves IDs, coordinates, raw type labels, and special values, validates at most 100 entries and the observed 0–2559 by 0–319 extent, and maps the eleven accepted tags (`tone`, `pad`, `smpad`, `mdpad`, `lgpad`, `special`, `bridge`, `levhub`, `levshld`, `feature`, `feattrig`) to explicit kinds and original renderer class/subtype/variant fields. The original parser rejects unrecognized tags. `FUN_00461b3b` assigns `tone` to renderer class 1 (the start-marker class) and `pad` plus the size-specific pads to class 0; subtype/variant and raw tag remain distinct, so dispatch `tone` to its pool animation before generic pad rendering. Local `shapes.txt` maps `POOL` to `data\tone.shp` and `PADS` to `data\pad.shp`; `bldinf.txt` defines `POOL` frames 2–40 with a three-tick ping-pong (`CHUG 2 40 3 P`) and `PADS` with its separate loop. The remake renders `tone` using the 40-frame `TONE.SHP` pool animation; Ghidra shows the POOL special case in generic `FUN_0040bf98`. `FUN_0040ab42` is the separate `PADS` site animation. Its 27-frame `PAD.SHP` asset forms three nine-frame size groups for `smpad`, `mdpad`, and `lgpad` only. `levshld` also has class 0/subtype 0 in the raw parser, but `pad.txt` and `bldinf.txt` map the Leviathan shield item variants to base frames 1–14 of `SPEARS.SHP`; because `ISLANDnn.TXT` does not identify a variant for each row, the remake leaves these as inspection markers instead of guessing a shield frame. This classification follows the shipped asset metadata and original renderer evidence; the animation tick cadence remains approximated by the remake's 33 ms timer. The 33 ms window timer is an approximation of the original game tick cadence; tribe visibility flags are not represented in `ISLANDnn.TXT`. The remake also loads the matching `i%02d-feat.shp` for each island and transcribes the non-triggered branch of `FUN_0040b345`, including its per-island frame selection and world coordinates driven by the location's `special_value`. `FUN_00432940` is the original location draw-order comparator and sorts by ascending world Y; the remake uses that order for pad and feature layering. Frame counts in the local corpus match the renderer's referenced indices for all 15 islands. Active feature overlays now follow all seven reveal stages from the live +0x30 counter; HZT treatment based on altitude remains unimplemented. Exact runtime palette/HZT treatment is not reconstructed. A drawable runtime item now replaces `PAD.SHP` at its occupied site; an unoccupied typed pad keeps its animated construction ring. The `PIT_Object` catalog row (runtime item ID 1) has no base building SHP, but its generated collectible overlay uses `+0x24` to select a frame from `alltrigs.shp`. `PIT_FeatureTrigger` (item ID 3) remains omitted because its row is `noshape`; these item IDs are distinct from the island renderer-class field. class-3 `special` locations still use colored inspection markers, and the status footer and click-to-inspect interaction are remake scaffolding.
- The original initialization also passes the 3584-byte HZT member through `FUN_00410510` to build palette lookup tables. The remake now recreates both 8×256 lookup tables in `src/core/island_haze.c`: the HZT supplies seven 256-byte levels per bank, `FUN_004106dd` selects the second bank when its selector is zero, and `FUN_00410510` generates level 7 by nearest-color matching to RGB6 black or white while preserving index 255. The tables are loaded with each island palette. Their application to sprites is still pending because the scene-specific haze levels have not yet been reconstructed. Original non-pad site sprites, terrain effects, units, and simulation are also pending. Runtime captures from the remake show the actual island panorama and a selected site at `ToneRebellion_Remake/build/island_view/island-view.png` and `ToneRebellion_Remake/build/island_view/island-location-selected.png`; they are not captures of the original game.
- `Esc` returns from the map view to new-game setup; Left/Right changes the selected world size before or after entering the view.
