# Building rendering

# Runtime building-item rendering

The construction initializer `FUN_004528ca` does not write the modeled producer cadence at `+0x0c` or BARG double at `+0x50`; placement preserves both values on a reused site (REA `ev_cbf0731fafd218757f4537413f1660e5a9f54ddb78113b8c8fdd2b6fd8bc94b1`).

The generic renderer was identified in Ghidra as `FUN_0040bf98`: the remake resolves runtime item IDs through `pad.txt`/`bldinf.txt`, loads each item's SHP, and renders `BASE`, `CHUG`, `GLYP`, `INCI`, `CONS`, `PROD`, conditional `OCCU`, and `BARG` layers. `FUN_00450a71` advances the per-object `+0x3a` CHUG counter only when source flag `0x001` is set for class 0, and advances `+0x3c` GLYP progress while active; `FUN_004528ca` initializes created pads with flags `0x410`, counters zeroed by `FUN_004500c4`, and rate modifier `+0x32 = 1`. These counters and flags are stored per runtime site and advanced by the remake's simulation tick. The tick also advances CONS (`+0x40`, flag `0x004`) and PROD (`+0x42`, flag `0x002`) to their descriptor thresholds. A code-5 delivery to an idle class-2 item 2 starts CONS; its completion starts PROD, and PROD completion activates the paired bridge markers and WORLDPOS edge (`FUN_004669bd`). The completion handler reads the faction slot written at `+0x2c` to grant access to the neighbor island. The remake carries this path through the existing delivery task; the exact visible click that creates that task is still unknown (REA `ev_ff0149927c5527e42ad97c0ccb0ecff046537edadb26eb9fecf60e1403b49d28`, `ev_ba8f92a6919e9effc29fe5556388fe31c0f95c6bb6cec3f58b14ccedd642103d`, `ev_e249dd4d7d585f32ab8607da5566db19667f43516538d4d908601273c6cf70c1`). Other item-specific completion events, PROD projectiles/secondary effects, and the construction transition that sets flag `0x001` remain pending. Ghidra assembly shows `BARG` frame selection uses `(last-first+2) * *(double *)(object+0x50)`, rounds with `FISTP`, offsets from the first frame, then clamps; the remake ports that mapping. For staff buildings `FUN_0045cd75` updates the double to `+0x30 / 250` while a worker trains, then fades it by `0.25` per tick when no trainee is active; the remake ports both updates (`ev_909283391ee942c84efc21a8f5ebd7d5f7`). `FUN_004528ca` leaves this field untouched on placement, so a reused site preserves the native value. The separate construction-site routine is `FUN_0040ab42`, bound to `PADS`; local `bldinf.txt` declares `CHUG 1 9 1 L`. Its source formula divides global ticks by segment speed plus object `+0x0c`, then adds world-x modulo 23. The remake currently supplies zero for that unresolved object adjustment. A site circle disappears as soon as its runtime item ID is nonzero, even if its sprite asset cannot be drawn.

Offset correction: `FUN_0040bf98` draws the animated `PROD` frame at the item anchor. The `PROD` descriptor's x/y offsets are used only by the conditional threshold overlay drawn after that frame. The remake follows that distinction now; previously it incorrectly displaced the animated frame too.

The generic runtime renderer also shows the corresponding resource marker (frame 0 from `bildtone.shp`, `tonecrys.shp`, or `magctone.shp`) at the descriptor offset while a producer's output is pending. Ghidra's `FUN_0040bf98` gates this marker on a reached active PROD threshold or a nonzero pending output; owner-specific item IDs are normalized in the remake. Evidence: `ev_5e71afc99fd4ab5273b4c07b5dc6e556212856d3462a715fb6a2569b19ce1407`.

Active producer IDs `0x25..0x27` also use source `+0x2c` as an 11-tick scratch counter; when it rolls over, `FUN_00450a71` clears `+0x36`, which is checked by floater pickup retries. The simulation now ports that reset so a prior empty pickup check cannot leave a waiting worker stuck. Evidence: `FUN_00450a71`, `ev_42f2f9245939e039d5f3d185117501094fc590095774d6ab3a5a5a725b2871e7`.

Base item `0x2a` passively adds one Build Tone to raw `+0x28` whenever the low byte of the global tick wraps to zero, stopping at 20. The island simulation now tracks its source tick and applies this production for the normalized item ID, including player-owned variants. REA evidence: `FUN_00450a71` `ev_d784718e66856eb3e6bda40782856ee703078c3ca97473d251a309b62b884fd8`; `FUN_00452794` confirms the item ID is resolved with the player's `pad.txt` row `ev_5d2b9a1a541dabdd9188bff2e43c3e909d2f1d7cc1a5a3ad07efac0aefe18df9`.

The same renderer selects the BASE frame from the signed runtime short at `+0x4a`, then subtracts one when flag `0x20` is set and clamps to the BASE descriptor range. Island rendering now passes that runtime field into the frame selector; it no longer uses the unrelated, never-updated render mirror. This makes tier/frame changes written to `+0x4a` visible. Direct Ghidra evidence: `ev_5e71afc99fd4ab5273b4c07b5dc6e556212856d3462a715fb6a2569b19ce1407`.

An upgrade increase sets flag `0x020` and resets `+0x48`; `FUN_00450a71` advances that short and clears the flag after it passes `0x17`. While the initial flag `0x010` is also set, it advances the shared short first, and at exactly 100 calls `FUN_00452fcb` to clear the animation layers before clearing `0x010`. The island tick now ports both timers in source order, including their shared-counter behavior and the temporary BASE frame adjustment (`FUN_004672ef` `ev_a34a7d43a13c0b88792bdd0607aed514c0b76a6b5f642d473d153cf9b25922bd`; `FUN_00450a71` `ev_42f2f9245939e039d5f3d185117501094fc590095774d6ab3a5a5a725b2871e7`; `FUN_00452fcb` `ev_15b50056a48ef8ef5235dae1b08a20fafc99934ab3cdda8f64996880cd8fb9e4`).

Lethal damage to a destructible site sets flag `0x080` and resets the shared `+0x48` short. `FUN_0040bf98` then draws `crumble.shp`: item sizes 0/1/2 use 9-frame bands starting at 0/9/18, and class 1 starts at 27. Its frame advances every three ticks, cycles the last five frames, and folds the timer back after 88; from tick 31, the building itself shifts down while the crumble stays at its original anchor. Island rendering now loads and draws that overlay, and `FUN_00450a71` clears the site after `+0x48` exceeds 100. The existing cleanup cancels local tasks and releases staff/resource links. Evidence: `FUN_0040bf98` `ev_7671b0496e4b9427ec15c32158ee307120137e3f7fb0f7d5922b649cf991117e`, crumble resource registration in `FUN_0040d48c` `ev_73ab4cfe2e0a4abd46364c0a269b43a720d140522d973ee47fa1da530dd6e5e6`, and frame-band bytes at `0x0049ad10` `ev_b37ee830f616b7df76b753bf6d29d6f5be8c463528f3f47319e039a1c8ec5157`. The native type-8 notification and owner-wide callback remain unmodeled (`FUN_00452ae7` `ev_cbda1e0ac814e3e3033606f86969a16622bf6114dee3173e52ac5ba83789cf12`).

The staff-building tick retains the incremented `+0x30` short even on the tick it reaches the 251 training threshold; only the BARG double update stops at that threshold. The remake now preserves that final counter value when training completes (`FUN_0045cd75`, REA `ev_909283391ee942c84efc21a8f5ebd7d5f7cc6c8328ccf0444922199fe6ae90d8`).

For class-2 bridge markers, `FUN_004503bd` starts CONS from delivered code 5 only while flag `0x004` is clear. Every other artifact delivery (including code 5 while CONS is active) calls `FUN_0045f075(code, 1)` and credits the player's inventory. The island delivery validator and deposit now both support this fallback; previously the deposit handled it but the validator rejected the task before assignment (`FUN_004503bd` `ev_ba8f92a6919e9effc29fe5556388fe31c0f95c6bb6cec3f58b14ccedd642103d`; `FUN_0045f075` `ev_6f2fbc4c89a115b0a145c3cfe30ddd583750f16a414b4ab192d3ec96aab3c1a3`).

Construction-site animation now passes the original pad-size subtype (0/1/2 for small/medium/large) into the `FUN_0040ab42` phase formula. `FUN_00461b3b` stores that subtype at the location-record offset consumed as `object[+0x0c]`; the previous renderer incorrectly supplied zero for all site sizes.

Island rendering loads the original `pad.txt`/`bldinf.txt` metadata from `TONE00.COB`, resolves runtime item IDs present on the selected island, and loads their SHP sheets from `TONE01.COB`. It composites the item layers selected by `FUN_0040bf98`; CHUG uses the per-item `+0x3a` counter divided by its declared speed, with loop/ping-pong over the frame range. The session tick advances active CONS (`+0x40`, flag `0x004`) and PROD (`+0x42`, flag `0x002`) counters and clears each flag at the threshold obtained by `FUN_00456b8d` / `FUN_00456bd0`; code-5 delivery starts CONS on class-2 item 2, which chains into PROD and activates paired bridge markers when PROD completes. Completion grants the faction at `+0x2c` access to the neighbor island. The visible producer of the code-5 task remains unknown; other completion callbacks remain pending. GLYP uses `+0x3c`, INCI uses `+0x3e`, and BARG uses the item double field at `+0x50`. `FUN_0040ab42` remains specific to `PADS`; it is not the generic building animator. Unoccupied `POOL` tone fields and `PADS` retain their own entity renderers, and construction rings are hidden for occupied records. The separate `IWConstruct` item-icon grid remains open.

The source active-bit recalculation (`FUN_004539e9` → `FUN_00453958`) explicitly clears bit `0x001` and refuses to set it when raw owner field `+0x14` equals `-1`, before checking maintenance/state flags and visibility. The remake applies the same ownerless guard in `game_session_recalculate_location_active_with_visibility`; this prevents an unowned or unplaced site from becoming active just because its visibility mask contains the computed bit. REA evidence: `ev_ae4dbc41b2cc5c7b5e3b8c5073fad2cd152142631ae77bb433d04cdc7589c89d`.

`FUN_00450a71` also advances `+0x44` while flag `0x100` is set, clears that flag after the short exceeds 999, and runs active-state recalculation every tick. Since `FUN_00453958` requires `+0x44 < 20` when `0x100` is set, the building stops counting as active at tick 20; activity is recalculated again when the 1000-tick timer expires. The island tick now ports this temporary deactivation and refreshes player maintenance or Leviathan eligibility when the active bit changes. REA evidence: `ev_3729a59fadd8a0ad906dcd6ad224dbc4a6a0c5ee450cd7533b493e046d3edb1b`, `ev_ae4dbc41b2cc5c7b5e3b8c5073fad2cd152142631ae77bb433d04cdc7589c89d`.

The same source update advances `+0x46` every 16 ticks while `+0x58` is positive: state 2 clears itself and recalculates activity, while state 3 clears the runtime site. The remake now carries those delayed transitions through the existing site cleanup and active-state paths. State 1, set on a moved-from site, remains inert because the source's update gate skips an unowned empty site. REA evidence: `FUN_00450a71` `ev_3729a59fadd8a0ad906dcd6ad224dbc4a6a0c5ee450cd7533b493e046d3edb1b`.

`test_building_render` covers the `bldinf` animation layers, source counters/flags, offsets, BARG's x87 round-to-even frame mapping, and `CHUG` loop/ping-pong timing; it can validate the actual local text corpus with `test_building_render.exe <pad.txt> <bldinf.txt>`.

World-map rendering and entry now use the original island-access rule: Ghidra's `FUN_00471e66` selects the `SMISLE` frame group `+15` for inaccessible, `+0` for accessible and `+30` for accessible-and-selected islands; `FUN_004711e2` draws a selected island name only when `FUN_0047117d` permits access. The remake uses the selected single-player tribe's access bit for these decisions and entry. Tests cover the frame-group choice. Multiplayer active-mask initialization and island-discovery updates remain unimplemented. Evidence and limitations are documented in the parent [`FUNCTION_GUIDE.md`](../../FUNCTION_GUIDE.md).

The Trade panel now renders the source-described 3×3 offer table with row art from BILDTONE/TONECRYS/MAGCTONE. Left and right cell clicks change each displayed offer by 10 within 0..1000; TradeZERO clears the table and TradeDOIT stores one type-0xb outbound request per nonzero recipient. These requests do not alter resource stocks because multiplayer transport and receipt are not implemented. Evidence and limits are recorded in FUNCTION_GUIDE.md; regression tests are in test_game_trade.

The Diplomacy panel now uses the original DIPLOMA frames, source-derived hover zones, recipient order, captions from `newtext.txt`, and local policy/recipient toggle state. Outbound subtype-10 requests are retained in `GameSession`; multiplayer transport and `FUN_00428191` player banners remain unimplemented. See FUNCTION_GUIDE.md and `test_game_diplomacy` for the evidence and covered cases.

The render-facing mirror follows the active counter and returns to zero when inactive; `FUN_0040bf98` draws the descriptor's first frame for the `-1` sentinel.
